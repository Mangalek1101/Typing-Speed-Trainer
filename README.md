# SpeedType Ultra Multi ??

Профессиональный мультиязычный тренажер слепой печати на Python. 

## Возможности
* **Поддержка RU/EN**: Мгновенное переключение языка текста.
* **Интеллектуальная подсветка**: Визуальная индикация правильных букв и ошибок в реальном времени.
* **Расчет WPM**: Точный замер скорости печати (слов в минуту).
* **Современный интерфейс**: Построен на базе библиотеки `customtkinter`.

## Установка и запуск
1. Установите зависимости:
   `pip install -r requirements.txt`
2. Запустите приложение:
   `python typing_multi.py`
